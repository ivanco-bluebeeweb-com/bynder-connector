# Bynder Connector — Preparation

**Category:** C43. Digital Asset Management (DAM)  
**Vendor URL:** https://bynder.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Bynder** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C43. Digital Asset Management (DAM)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **бренд-менеджер** сталкивается с задачей: **централизованное хранение, организация, брендовый контроль и дистрибуция корпоративных медиа-активов**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Bynder переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **бренд-менеджер, медиа-продюсер, арт-директор**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `поиск медиа-актива по брендовым тегам -> создание публичной коллекции -> безопасная выдача ссылок`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Bynder.
